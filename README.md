# Agentic-RAG-System-LangGraph-LangChain-FastAPI-Docker
Built an Agentic RAG system using Python, LangChain, LangGraph, FastAPI, and Docker. Implemented intent classification, workflow routing, semantic retrieval with Hugging Face embeddings and ChromaDB, and context-aware answer generation using Groq LLM. Exposed the application through REST APIs for efficient document question answering.
